## 布局与外观

这是一个 PETG 打印的桌面双层开放式框架：上层主板平放、显卡正常直插，下层电源横放并居中。前上方设置两把并排的 140 风扇，向主板及显卡区域送风；背部保留主板与显卡接口、电源排风通道。

参考当前装配：[V13 Fusion 装配图](../outputs/ATX-Desk-v13/Assembly.png)。图中的蓝色框架、浅色主板梁、橙色附件、绿色主板和透明显卡只是识别部件的显示颜色，不限定实际耗材颜色。CPU、内存、显卡和电源的简化实体用于检查布局，不能当作完整实物模型。

保留左右及前侧承重框架。CPU 右侧保持垂直并与上方结构对齐；PCIe 左侧单侧内收，使底部宽度达到 290。后侧由连续横梁连接左右框架，不设置遮挡电源排风的大面积支撑板。

早期的双侧内斜、下层前挡板、显卡尾部托架、电源上方完整限位框，以及后横梁中间拼接，均不属于本基线。

## 朝向与气流

沿用硬件文档的坐标：X 朝 CPU 右侧，Y 朝背部接口，Z 向上。

| 部位 | 风格 1 的方向 |
| --- | --- |
| 主板 | 水平放置，CPU 在显卡插槽右侧，内存在右前侧 |
| 显卡 | 插第一条长 PCIe，风扇朝 −X，背板朝 CPU 一侧 |
| 主板 DP 和显卡显示接口 | 均朝后，即 +Y |
| 电源 | 下层横放，进风大风扇朝下 −Z，排风朝后 +Y |
| 两把机箱风扇 | 前上方并排安装，朝后 +Y 送风 |

电源通过底部开放托架吸气，托架只承托外壳边缘并限制位移。细扎带用于防脱。整机主要载荷经框架传递至桌面，不通过电源外壳承担。

## 承重与连接

主板九个安装点通过三根纵梁和侧部框架向下传力。左右框架、前框、后横梁和底横条形成闭合连接，避免只有孤立立柱支撑。前框角部有连接孔，中缝通过一体连接耳固定；底横条与侧框使用搭接座及螺丝连接。

显卡固定塔底部直接连接后部承重横梁，塔身设置加强筋。上部可调托片承接显卡金属挡板的安装耳，下部可调接收件容纳两个金属插脚；上下分别定位，避免仅靠一个横槽固定。可调件从背面锁紧，滑块内放短热熔螺母。实卡插脚和安装耳仍需试装核对，模型可调不等于已经验证实物适配。

两只风扇面板分别带安装耳，连接到一体底梁；底梁通过四个锚点连接前框。风扇本身为外购件，模型里的轮廓和十字只表达硬件位置，不应作为需要打印的叶片或风扇本体。

## 装配材料与顺序

以 M3 × 6 螺丝和 M3 H4.5 OD5 短热熔螺母为主，按约 48 组准备。现有 H8 螺母不能直接替换所有短螺母孔。风扇与面板之间另用匹配风扇的紧固件；电源另备宽约 3 的细扎带，绑带路径避开进风网、排风网、AC 插口及开关。

先安装热熔螺母，再依次装底横条及侧框、前框、后横梁、电源托架、主板纵梁、显卡塔和可调件、风扇底梁及面板。先轻紧，整体校正后再锁紧。采用完整 V13 连接体系，不根据已打印情况混用旧版连接件。
