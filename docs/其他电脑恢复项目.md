# 在其他电脑恢复项目

此仓库保存硬件设计资料、风格 1 和风格 2 的 CAD 模型、各版本 STL、Bambu Studio 摆盘及参数、安装说明书、参考图和建模脚本。历史版本与打包 ZIP 保留，用于追溯。

## 获取完整项目

仓库为私有仓库，需要登录有权限的 GitHub 账号。安装 Git 后执行：

```sh
git clone https://github.com/rapidrabbitsliu/pc-chassis-designs.git
cd pc-chassis-designs
```

也可以使用 GitHub 网页的 Code → Download ZIP，下载后完整解压。文件不使用 Git LFS，不需要额外下载大文件。项目可以放在任意目录；优先直接打开下表的成品文件，无需重新运行建模脚本。

### Fusion

安装 Autodesk Fusion，通过“从我的计算机打开”选择所需 `.f3d` 文件，即可恢复保存时的模型。桌面账号、Fusion 云端项目、软件偏好和 MCP 连接需要在新电脑配置，仓库不携带这些账号或连接状态。

### Bambu Studio

安装 Bambu Studio，将 `.3mf` 作为项目打开，选择载入项目内的打印机、耗材和工艺参数。风格 1 V15 共 10 盘：前 9 盘保留原名称及“已打”标记，原 P12/P13 已更新；第 10 盘是两件的临时修补副本。需要打印时只选择相应盘，避免重复打印。

V15 第 10 盘于 2026-10-24 在 Bambu Studio 02.07.01.62 切片通过，预计 6 小时 9 分、132.17 g PETG。工程保存模型和参数，没有嵌入 G-code；在新电脑上重新切片。打印机登录、设备绑定、AMS 槽位和实机校准由新电脑重新确认；仓库中的耗材编号不代表实机槽位。

### 说明书与图片

用浏览器打开本地 `.html` 文件。保留整个目录结构，以便说明书的相邻图片和链接可用。GitHub 文件预览不会直接运行 HTML，先下载再打开。

## 校验下载是否完整

安装 Python 3 后，在仓库根目录运行：

```sh
python tools/verify_project.py
```

脚本仅使用 Python 标准库，按 `project-files.sha256.json` 检查文件数量、大小和 SHA-256。全部通过表示文件与上传时的清单一致；这项检查不代替 CAD 配合、承重、热熔或实物装机验收。

## 继续修改与同步

`work/` 保存各版本建模、导出、摆盘和检查脚本，`outputs/` 保存成品及其来源。部分历史脚本包含原电脑的 `D:/personal-files/...` 或 `C:/Users/liu/...` 路径，以及 Fusion 专用 API；不要直接全量执行。需要重新生成时先检查对应版本脚本中的输入、输出路径，配置 Fusion MCP，并按脚本导入安装 Python 依赖。日常打开已有模型或打印工程无需这些依赖。

安装说明书维护流程保存在 `outputs/skills/chassis-assembly-manual/`，项目入口为 `AGENTS.md`；新电脑没有该本机 skill 时，可从维护副本读取。

完成修改后，用 Git 提交并推送；换电脑继续工作前先拉取。要更新完整性清单，在已暂存准备上传的项目文件后执行：

```sh
git add .
python tools/verify_project.py --write
git add project-files.sha256.json
git commit -m "Update chassis design"
git push
```

新版本应保存到新目录，并同步更新根目录 README 的入口。不要用旧的补打 ZIP 覆盖最新完整工程。
