V03 布局预览：单侧内收 + 双140 mm上层送风

本版用于看布局，尚未完成所有拼接、紧固、风扇线缆和打印支撑设计，不用于直接打印装机。
V02与V01保留。

已落实
1. CPU一侧上下均为垂直面：侧框X282.45..298.45 mm，不再倾斜。
2. 仅PCIe一侧内收：上端外缘X=-4 mm、底部外缘X=8.45 mm，内收12.45 mm。
3. 底部接触桌面范围X8.45..298.45 mm，总宽290 mm。
   这对应用户从9号孔的横向位置朝8、7号方向量出的290 mm桌面带。
   CPU侧上端支撑也略向主板内侧移动，以保持该侧垂直且落在桌面带内；9孔位置不改。
4. 主板元件面俯视、后接口朝上：CPU/内存在右，第一条长PCIe在左中，第二条长PCIe更靠左。
5. 电源仍居中，进风面朝CPU侧，与显卡风扇相反；出风朝后置接口侧。
6. 显卡尾托保持删除，仅保留后挡板固定架与滑块。

两把上层风扇的方案
按用户选择，暂采用140×140×25 mm方框风扇。
两把并排布置在主板前缘（图中内存靠近的那一边），从前朝后置接口方向送风。
左右各负责一片上层区域：一把靠显卡区域，一把靠CPU/内存区域。
目的是提供穿过开放框架的辅助横向气流，不是密封风道；不替代CPU或显卡自身散热器。
风扇采用可拆框与共用下横梁，不固定在显卡或内存上。

尺寸与空间代价
左风扇X12.4..152.4，右风扇X156.4..296.4 mm，两者间隔4 mm，总横向284 mm。
风扇位于Y=-50..-25 mm，安装框Y=-25..-19 mm，主板前缘Y=0。
因此不增加横向宽度，但前方相对主板边缘增加50 mm占用。
风扇垂直覆盖Z210..350 mm；主板PCB顶面209.6 mm。
风扇后方至PCB前缘留19 mm；主板边缘插头、线缆弯曲半径仍需实物核对。
底部仍为290 mm；上框宽度与前后尺寸不受这条横向限制。

风扇孔距尚未以用户实物确认
当前孔距先用124.5×124.5 mm、安装孔径4.5 mm作参考。
参考来源：Noctua NF-A14 PWM官方规格，140×140×25 mm、孔距124.5 mm。
https://www.noctua.at/en/products/nf-a14-pwm/specifications
这不代表用户已选择该型号。具体风扇型号确定后，需再核对孔距、减震垫、外框突起及螺丝长度。
风扇通过实际安装方向实现图中的前进后出；参考模型只表示包络和方向。

验证范围
21个候选打印件与主板PCB、显卡、电源、两把风扇简化包络一起进行实体干涉检查，排除共面接触后为0处。
Fusion时间线473项健康；底部宽290 mm及CPU侧垂直面已通过几何坐标核对。
没有进行风量、温度、噪声测试；没有真实CPU散热器、所有元件、插头和线缆的完整模型。
显卡主插槽位置仍为约数估计；没有实物试装、承载或PETG热态蠕变验证。
