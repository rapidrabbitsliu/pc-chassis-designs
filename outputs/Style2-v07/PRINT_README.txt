风格2 V07｜双140mm侧向送风版

按内存一侧向主板后置接口方向送风，Fusion坐标为-X。
主板竖放，因此两只风扇在右侧上下排列：上方CPU/内存，下方显卡。
风扇本体先按140×140×25，四孔距124.5×124.5；具体型号和孔位仍需核对。
把风扇实际风向箭头朝主板接口侧安装，不能只凭叶片或外观判断方向。

模型：Style2_V07_Dual140_Colored.f3d。蓝色为19个打印结构件，半透明灰色为硬件示意。
打印：Style2_V07_A1_PETG_All_Parts_13_Plates.3mf。
单件毫米STL在PRINT_STL目录。灰色示意件不打印。
新增第11盘风扇立梁、第12盘GPU风扇框、第13盘CPU/内存风扇框。
第3盘原右立柱新增4个安装孔，需要使用V07右立柱配新风扇架。

打印基线：A1/0.4，PETG，纹理PEI，0.20层高，5墙、40% Gyroid，顶6底5。
245°C喷嘴、70°C热床、13mm³/s最大体积流量，逐层、100%比例。
底脚brim3，其余5。按项目内的平放方向打印，关闭支撑及擦料塔。
实际发送前把材料映射到当前PETG料槽；重新打开后如软件要求，重新切片。

需要准备的连接件：
1. M3热熔螺母，长4.5mm、外径5mm：实际62个，建议准备70个。
2. M3×6mm螺丝：实际62个，建议准备70颗；普通头径需小于6.6mm。
3. 两只25mm厚风扇：暂按M4×40mm穿透螺丝8颗＋普通M4螺母8个固定，可配垫片。
   这是普通螺母，不是热熔螺母；先核对实物风扇安装孔能否通过M4。
4. 电源仍需绑带防止向上脱出，左右底挡只是定位。

新增连接：风扇立梁用4颗M3×6固定到右主板立柱；每片风扇框用2颗M3×6固定到立梁。
热熔螺母仅装在4.7mm接收孔，不装在3.4mm螺丝通孔或6.6mm头井内。
立梁四个深头井需要能伸入的细柄螺丝刀或内六角工具。

总高314mm；当前模型包络前后306mm、含风扇左右约300mm；落地底座保持V06尺寸。
CPU散热器、内存和真实接插件尚未完整建模；母槽仍按照片占位。
零干涉、切片可通过不等于实物适配、强度或散热性能验收。
