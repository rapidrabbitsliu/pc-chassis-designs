# 机架安装说明书

先确认用户认可的模型和打印版本，再编写对应说明，默认中文。制作文档不代表获准改 CAD、重切片或发送打印。

## 读取项目依据

从当前项目 README、版本说明、parts.json、盘号表、建模源文件和检查报告确认实际版本。首次使用或版本变化时读取 [references/project-context.md](references/project-context.md)。其中 V09 是历史基线，不可不经核对直接复用其尺寸、数量或安装关系。

## 让读者对应实物

- 每个独立打印件分配稳定短编号及中文名，保留 CAD/STL 文件名与盘号；沿用已有编号，新件追加，删除件的旧编号不得指向其他零件。
- 每件至少一张独立图，说明识别特征、数量及螺母数。镜像件区分左右，相同件明确可互换与安装位置；说明左右视角。
- 零件图、步骤和表格编号一致；步骤编号链接到零件卡片。未改模型时注明编号只在文档中，没有刻入打印件。
- 每步至少一张完成状态图，清点步骤可用全件总览。区分本步新增、此前已装、参考硬件。容易装反、被遮挡的安装面、热熔压入、电源导入和限位按需补细节图。
- 图来自对应 CAD 或网格，不用生成式图片猜测孔位与装配关系。未建模的散热器、线束、绑带、螺钉和补充固定件明确说明，不能把包络图当作已固定完成的证明。

## 核算紧固件与步骤

1. 从实际孔位/建模源重算螺母与螺钉数量，按接收零件和连接关系列账。区分热熔盲孔、通孔、螺钉头凹槽，不在每个可见孔内都装螺母。
2. 列螺纹、螺母长径、螺钉长度与头型尺寸限制，需要量和建议备量分开。风扇贯穿螺栓/普通螺母、原厂螺丝、待实测固定件另计。
3. 先完成热熔再装电子硬件，并避免框架遮挡孔口；每组孔标所在面、压入方向和测量基准，区分地面高度与零件端面高度。
4. 顺序按承力框架、托件、硬件展开，检查工具可达性；每步列新增编号、螺丝数量、方向、检查点。
5. 托座限位不等于防脱固定。若缺显卡挡板锁紧或母槽适配，写明待完成条件，不虚构安装完成。强度、热性能与长期 PETG 蠕变不得以几何干涉检查代替。
6. 材料工具包括压头、匹配螺丝刀、卡尺、修边工具及需要的绑带和接线件；热熔温度、电流等依厂家/实物核定，打印温度不直接当热熔温度。

## 生成、验证与交付

沿用现有说明书版式更新。单文件 HTML 内嵌图片/SVG，包含目录、移动布局、打印样式、可勾选检查表；正文和图片均离线可用，不依赖 CDN 或临时服务。独立 PNG 可作为维护源。

插图和脚本复用时读取 [references/illustration-workflow.md](references/illustration-workflow.md)。浏览器预览若被安全策略拒绝，不换浏览器/服务绕过；改做静态与直接图片检查，并准确说明验证范围。

运行 `python <skill目录>/scripts/validate_manual.py <说明书.html> --parts <件数> --steps <步数>`。验证器只检查结构；还需核对插图与模型、孔位账与连接账、裁切和字可读性、箭头是否落在实体上，以及装配前置条件。

更新对应版本说明及用户需要的压缩包。替换 ZIP 同名条目，避免重复；关闭写句柄后再校验 ZIP。需跨设备查看的媒体预览通过原生附件交付，不能只给本地路径。最终给说明书链接及未完成的实物适配项，不宣称已装机验证。
