# 可信插图生成

优先使用已有对应版本网格，不改 CAD。单件图独立居中，步骤图保留装配坐标；已归零平放的 PRINT_STL 不适合直接画装配状态，V09 的 Raw_STL 可用。根据 parts.json 三轴尺寸核对单位，Fusion 内部为厘米，不可盲目统一乘10。

缺参考硬件时，发现 Fusion MCP 脚本工具，查询使用的 API 文档，确认活动文档版本后导出 REF_ 组件；不保存云端文档、不改几何、不混入打印件。脚本定义 `def run(_context: str):`，不捕获异常。传输中文路径曾发生乱码，可用 Python Unicode 转义传递中文。

项目 `work/illustrate_manual_v09.py` 提供 NumPy/Pillow STL 正交投影、背面剔除和深度排序。适合简单机械件；新版本需修改清单，不能假设自动识别新设计。若遮挡排序不可靠，改用 CAD 截图。独立图提供编号、中文名和识别特征，细长件适当放大。立柱的前/背/侧孔必要时加分面图。

每步维护累计组件列表，新增件高亮、旧件灰蓝、硬件浅灰。第一步若显示清点全部，第二步不能与它做集合差判新增；要显式标明新装的立柱和底脚。未建模的线缆、散热器、绑带、补充固定件写在图注中。

引线仅标相关件，落点选可见实体面，不能落在中空框的包围盒中心。避开标题图例，检查长引线遮挡。视角变化时仍按模型身份命名左右，必要时说明从哪一面看。

压入螺母、连接剖面、斜坡限位、间距与气流可用自绘 SVG，注明非比例示意；不猜未知硬件结构。图片 Base64 内嵌 HTML，并保留 PNG 维护源。检查单件卡片数量、编号、锚点、每步图片和离线资源，再直接查看图片，核对裁切、可读性、引线和颜色。不得把静态验证写成已浏览器测试或已实体测试。

V09 图解生成是在基础 HTML 上增补，不幂等；重建先运行基础生成再增强一次。打包时替换同名条目，关闭写 ZIP 后再 `testzip()`。
